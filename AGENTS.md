# Leaf source location

For Leaf work, use the **wordcraft-saving** branch. This main branch retains the earlier ApexDesk prototype and landing documentation.

Read the [current AGENTS.md](https://github.com/frandavid100/leaf/blob/wordcraft-saving/AGENTS.md), [project state](https://github.com/frandavid100/leaf/blob/wordcraft-saving/PROJECT_STATUS.md), [decisions](https://github.com/frandavid100/leaf/blob/wordcraft-saving/docs/DECISIONS.md) and [architecture](https://github.com/frandavid100/leaf/blob/wordcraft-saving/docs/ARCHITECTURE.md) there before implementing a Leaf task.

Inspect the checkout and preserve local changes before switching branches. Do not implement current Leaf changes in the historical ApexDesk source. Roadmap proposals do not authorize new work by themselves.
