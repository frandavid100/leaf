# Editable headers, footers and page numbers

Alpha.9 introduced direct editing. Alpha.10 adds the [section configuration and validation described here](PAGE_OPTIONS_PROOFING.md).

The document menu’s Insert submenu contains Header, Footer and Page Number. Header/footer text is edited directly in the document canvas with the existing keyboard, clipboard and formatting tools. Click existing text, or double-click an empty top/bottom margin to create a page story. Click outside the header/footer region to return to body editing; a click on surrounding blank canvas or Escape restores the previous body selection. The extra mode bar is removed in alpha.16. Editing outlines mark the body boundary without modifying the document.

The page-number dialog inserts PAGE and optional NUMPAGES at the captured current cursor, including in body text, headers or footers. Alpha.16 removes the Position and alignment controls; the current paragraph alignment is retained. The insertion is one undo step and stale document/selection targets are refused. Formatting, deleting or moving fields uses ordinary editing.

Existing first/even/default variants and inherited stories are resolved from the actual displayed page. Absent even variants can still reuse the default story instead of becoming independent: [confirmed reduced reproduction and open #7](ISSUE7_TRIAGE.md). Alpha.10 adds variant/section controls in Document Properties and preserves inactive associations. Exact ODT distances and section links use Leaf extension attributes; external editors may ignore or strip them. General field-code editing and full ODF page-style fidelity remain outside this increment. PAGE/NUMPAGES ODT preservation required the isolated formats patch; arbitrary field instructions are not claimed.
