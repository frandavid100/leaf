# Leaf

<img src="data/icons/hicolor/scalable/apps/leaf.svg" width="96" height="96" alt="Leaf icon">

**Powerful word processing, designed for GNOME.**

Leaf is a word processor for Linux with a native GNOME interface. Its goal is to make advanced document editing straightforward: everyday tools within reach, detailed options when you need them, and an uncluttered workspace that keeps your document at the centre.

## Write and organise

- Edit DOCX and ODT files with styles, tables and images.
- Start from personal templates and recover unsaved documents directly in a new tab.
- Use footnotes, comments, floating pictures and basic equations in DOCX and ODT.
- Add automatic contents, numbered captions and cross-references to DOCX documents.
- Paste or drop images; position and resize floating pictures, control text wrapping and adjust spacing.
- Arrange pages with columns, headers, footers and page numbers.
- Navigate by thumbnails, headings and bookmarks, and move whole heading sections.
- Search and replace whole words or selected content, including notes and headers, with optional regular expressions.
- Paste plain text, copy formatting, inspect document fonts and explicitly substitute missing families.
- Review spelling and add comments.
- Work across tabs and windows, configure autosave and recovery, then export to PDF or print.

English and Spanish interfaces, with light and dark appearance.

## The power behind the interface

[WordCraft 0.17.0](https://github.com/storytold/wordcraft/releases/tag/v0.16.0) provides Leaf's document engine. Its [documented capabilities](https://github.com/storytold/wordcraft/blob/02a802cbafe45b5c8fecc00490c8f6b78c5ba251/README.md#what-works-today) include advanced tools familiar from Microsoft Word, such as footnotes, bibliographies, tracked changes and mail merge.

The aim is to bring more of that power into GNOME while keeping the interface simple. Leaf currently exposes part of the engine's functionality; additional features need integration and testing.

## Try it and help it grow

Download the x86_64 `.flatpak` from [Releases](https://github.com/frandavid100/leaf/releases) and open it with GNOME Software. Updates are currently installed manually.

**Leaf is in alpha.** Test with copies of important files: complex document compatibility is still being tested. Advanced contents/field options, caption associations, original equation formatting, picture effects, language inheritance, changed following-paragraph styles and category metadata still require DOCX. Leaf blocks ODT saves that would lose supported document structures. By default, the Flatpak reads the system Templates folder with read-only access; custom folder selection remains unavailable.

Community translations are managed with [Weblate](https://hosted.weblate.org/projects/leaf/application/). Approval for free Libre hosting is pending.

## Development with AI

Much of Leaf's native interface code was generated by AI agents. The maintainer directs the design, chooses features and tests builds; implementation is largely delegated to those agents. Tests, packaging, documentation and original icon artwork have also used AI tools. [Scope and validation limits](docs/AI_ASSISTANCE.md).
