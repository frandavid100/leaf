## Leaf 0.1.0-alpha.45 — Missing fonts, stable reading position and complete tool placement

- Leaf warns about fonts actually missing from an opened document and labels substitutions honestly. Download Poppins styles from a pinned Google Fonts catalog, or open a local font file in the system font viewer. After installation, recheck and refresh rendering without replacing the requested font or changing the document history.
- Zooming and resizing preserve the visible reading position instead of jumping to an off-screen caret. Deleting a floating image, Undo and Redo preserve the current view; deliberate caret navigation still reveals its destination.
- Additional list galleries, numbering controls, individual table operations, creation actions, automatic fields and document breaks are available in toolbar customization, with existing ordering and all three placements preserved.
- Columns keeps its scope above the scrolling options, applies valid edits immediately and recognizes matching imported presets. Mixed sections stay explicit; scope changes and opening the preview do not edit the document.

WordCraft remains at the same 0.17.0 revision. Unequal-column text flow, footnotes, paragraph deletion formatting and other unintegrated engine contributions remain separate open issues. Recovery #231 still needs a reliable reproduction.

Automatic downloads initially cover Poppins Regular, Bold, Italic and Bold Italic. The user installs each style in the system viewer. The upstream bundle now grants network access for requested font downloads; FlatPark permissions are managed separately and its current package can require downloading font files outside Leaf. Windows packages remain occasional.

## Leaf 0.1.0-alpha.45 — Fuentes ausentes, posición de lectura estable y más herramientas configurables

- Leaf avisa de las fuentes que realmente faltan al abrir un documento y muestra claramente sus sustitutas. Permite descargar las variantes de Poppins desde un catálogo fijado de Google Fonts o abrir un archivo local en el visor de fuentes del sistema. Tras instalarlas, comprueba su disponibilidad y actualiza el texto sin sustituir la fuente solicitada ni alterar el historial.
- Cambiar el zoom o el tamaño de la ventana conserva la posición de lectura en vez de saltar al cursor fuera de pantalla. Borrar una imagen flotante, Deshacer y Rehacer mantienen la vista; navegar expresamente con el cursor sigue mostrando el destino.
- La personalización de la barra incorpora galerías de listas, controles de numeración, operaciones individuales de tablas, inserciones, campos automáticos y saltos. Conserva el orden elegido y las tres opciones de colocación.
- Columnas mantiene el alcance visible sobre las opciones desplazables, aplica los valores válidos de inmediato y reconoce los diseños importados que coinciden con un preajuste. Los alcances mixtos se muestran expresamente; cambiar el alcance o abrir la vista previa no modifica el documento.

WordCraft conserva la misma revisión de 0.17.0. El flujo de columnas desiguales, las notas al pie, el formato tras borrar párrafos y las aportaciones al motor todavía sin integrar siguen en issues separados. La recuperación #231 aún necesita una reproducción fiable.

Las descargas automáticas cubren inicialmente Poppins normal, negrita, cursiva y negrita cursiva. Cada variante se instala desde el visor del sistema. El bundle propio añade acceso a la red para las descargas solicitadas; FlatPark gestiona sus permisos por separado y su paquete actual puede requerir descargar las fuentes fuera de Leaf. Windows sigue publicándose de forma ocasional.
