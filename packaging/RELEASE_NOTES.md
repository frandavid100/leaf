Leaf 0.1.0-alpha.11 fixes standard ODF header/footer geometry: page-edge distances and body margins are exported using native ODF reservations and dynamic spacing. Independent Writer ODT files reopen with those properties, even after all Leaf metadata is removed. Supported standard geometry and number formats take priority over stale extension attributes after external edits. Existing rendering, engine revision and runtime dependencies are unchanged.

A focused one-off audit generates four synthetic DOCX/ODT fixtures, edits and saves them through LibreOffice UNO, then reopens/saves/reopens in Leaf. It checks body text, header variants, page fields, languages, section properties, link semantics and standard-only ODF imports. The audit records differences, rather than treating a completed workflow as a compatibility certificate; it is optional, not a per-release gate.

Known independent-editor limitations remain: Writer 24.2.7 drops DOCX w:noProof and materialises linked headers/footers as independent contents in these multi-section fixtures. Visible contents remain; Leaf cannot safely infer original links from identical text. General ODF border/padding/fixed-height/non-dynamic layout fidelity is not claimed. Unusual overlapping nominal margins and inactive header distances still use supplemental Leaf metadata. There is no change to user files until explicitly saved.

Install Leaf-0.1.0-alpha.11-x86_64.flatpak over alpha.10. GNOME 49 runtime; no automatic update feed. Existing localized interface, dark documents, HiDPI, lifetime and printing checks remain. Experimental AI-assisted development; test copies of important files. Weblate and public screenshots remain with the maintainer. No full 24-file corpus rerun.
