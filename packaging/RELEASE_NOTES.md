Leaf 0.1.0-alpha.12 exposes document text through GtkAccessibleText on the actual visible canvas. Character offsets use Unicode characters, translated to WordCraft UTF-8 positions. Readers can query characters, Unicode words/sentences, paragraphs and the actual soft-wrapped lines from WordCraft. Cursor, selection, insertion and deletion events follow normal editing and undo. There is no hidden GtkTextView, alternate document or editing buffer; keyboard editing and document formats still belong to WordCraft.

This first stage targets ordinary text and keyboard-driven reading, selection and editing. Full table/image/field semantics, rich text attributes, remote AT-SPI EditableText actions and newer GTK caret-setting/geometry interfaces are not claimed. Assistive-technology tests and remaining limitations are recorded separately. Generated Orca speech transcripts are automated evidence, not a human listening or braille-display test.

The existing English/Spanish UI, dark documents, ODF interoperability corrections and HiDPI support remain. Install Leaf-0.1.0-alpha.12-x86_64.flatpak over alpha.11. GNOME 49 runtime. Engine and renderer revisions unchanged; Unicode segmentation reuses the same crate already locked by WordCraft. No full document corpus rerun. Experimental AI-assisted development. Weblate and public screenshots remain with the maintainer.
