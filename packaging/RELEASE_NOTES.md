Leaf 0.1.0-alpha.10 adds a Headers and Footers page to Document Properties: section selector, different first page, odd/even pages, header/footer distances, numbering format and restart/continuation, and independent copies or links to the previous section. Page properties and header settings apply atomically. Original content is retained when separating sections; linking can be undone.

Spelling and Grammar is in the document menu (F7). Scans run in a worker; suggestions, replacement, Skip, Ignore All and a persistent custom dictionary use the pinned WordCraft proofing tools. Right-click misspellings for native suggestions. Text Language is in the Text popover: apply to the selection/typing position or document, mark text unchecked, and choose the language of new documents. English tools are built in; unmodified Spanish Hunspell dictionaries and credits/licenses are included. Other languages report when tools are unavailable. Grammar checking is limited to the engine’s rules, not a comprehensive grammar service.

ODT preservation fixes retain text languages, unchecked text, inactive page-part associations, numbering format and header/footer settings. Standard visible content is exported; Leaf extension attributes preserve section links, exact distances and original languages of unchecked text. Other editors may flatten links or ignore/strip these attributes. General ODF fidelity and full screen-reader canvas access are not claimed.

Install Leaf-0.1.0-alpha.10-x86_64.flatpak over alpha.9. GNOME 49 runtime; no automatic update feed. English/Spanish interface, dark documents and existing HiDPI/lifetime/printing regressions remain. No full compatibility corpus rerun. Experimental AI-assisted development; test copies of important files. Weblate setup and public screenshots remain with the maintainer.
