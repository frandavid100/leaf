## Leaf 0.1.0-alpha.43 — Focused formatting controls, shared colors and cumulative Repeat

- Start stays stable during character-format changes in an empty document. The sidebar keeps its width, and pinned formatting tools retain their options page. The combined Save Changes dialog uses distinct untitled names and adapts to narrow windows.
- Choose compact visual underline and strikethrough styles, one Normal/Superscript/Subscript selector, searchable fonts with document-font and script-aware previews, and languages with effective defaults and dictionary availability. Color, Highlight and Language use independent last-choice actions. Color properties share a compact palette, custom editor and recent colors.
- Repeat has a cumulative history: choosing an older formatting boundary replays the range in chronological order at the current target, with one Undo step. Ordinary Copy can supply Paste Formatting without inserting text or replacing the existing format-painter workflow.
- More Text, Paragraph and Elements tools can be placed individually in the toolbar. Alignment, indents, spacing, direction, pagination, sorting and tab stops have focused controls. Columns gains visual presets and a page-shaped preview; lists gain galleries, explicit removal, continuation, starting numbers and definition editing.
- Images gain visual crop with confirm/cancel, rotation, flips, alternative text and decorative metadata. Existing image groups open directly. Table properties use centimeter measurements, mixed selection values, explicit exact/minimum row height and separate vertical cell alignment.

WordCraft remains at 0.17.0. Existing engine issues #1/#99/#152 and intermittent recovery #231 remain open. Words-only underline cannot combine with every style; changing numbered designs without restarting remains limited. Table borders apply to the whole table, and cell-margin editing needs a public engine command.

The complete individual tool inventory and parts of the List, Columns, Borders, Image and Table proposals remain open (#259/#261/#262/#265/#267/#268). Image appearance properties and native assistive-technology exposure are not complete; saved alternative text alone does not establish screen-reader integration. Store description and public screenshots (#185) remain paused; Windows releases are occasional.

## Leaf 0.1.0-alpha.43 — Formato directo, colores compartidos e historial de Repetir

- Inicio permanece estable al cambiar el formato de un documento vacío. El panel lateral conserva su anchura y las herramientas fijadas mantienen su página. El cierre conjunto distingue los documentos sin título y se adapta a ventanas estrechas.
- Subrayado y tachado ofrecen muestras compactas; Normal/Superíndice/Subíndice comparten selector. Las fuentes permiten buscar, muestran las del documento y previsualizan los alfabetos compatibles. Los idiomas explican el valor predeterminado y la disponibilidad del diccionario. Color, Resaltado e Idioma repiten su última elección de forma independiente. Los colores comparten paleta, editor y recientes.
- Repetir incorpora historial acumulativo: elegir una operación anterior aplica desde ella hasta la última, en orden y sobre el destino actual, con un solo Deshacer. Copiar normalmente permite usar Pegar formato sin insertar texto ni sustituir el pincel existente.
- Más herramientas de Texto, Párrafo y Elementos se pueden colocar individualmente en la barra. Alineación, sangrías, espaciado, dirección, paginación, ordenación y tabulaciones tienen controles específicos. Columnas añade diseños visuales y una vista previa con forma de página; Listas añade galerías, eliminación explícita, continuación, número inicial y edición de definiciones.
- Las imágenes incorporan recorte visual con confirmar/cancelar, giro, volteo, texto alternativo y metadatos de decoración. Sus grupos existentes se abren directamente. Las tablas usan centímetros, muestran valores mixtos y distinguen altura exacta/mínima y alineación vertical de las celdas.

WordCraft sigue en 0.17.0. Permanecen los problemas del motor #1/#99/#152 y la recuperación intermitente #231. El subrayado solo de palabras no se combina con todos los estilos; cambiar diseños numerados sin reiniciar sigue limitado. Los bordes de tabla afectan a toda la tabla y editar márgenes de celda requiere una API pública del motor.

El inventario individual completo y partes de las propuestas de Listas, Columnas, Bordes, Imagen y Tabla siguen abiertos (#259/#261/#262/#265/#267/#268). Quedan propiedades de apariencia de imágenes e integración con tecnologías de apoyo: guardar texto alternativo no demuestra por sí solo acceso desde un lector de pantalla. La descripción y las capturas públicas de la tienda (#185) siguen en pausa; Windows se publica de forma ocasional.
