Leaf 0.1.0-alpha.23 updates document rulers, structural breaks, even-page headers and footers, and the Document Properties switcher.

- Four low-contrast ruler scales appear inside the edges of a page. The top ruler retains indentation and tab stop editing.
- Insert includes a Breaks submenu, and Navigation lists section starts. The ODT save guard protects break types the exporter cannot preserve.
- An even page displaying the odd header or footer can create an independent even variant when edited.
- Document Properties uses the native inline switcher on libadwaita 1.7 and newer. Older supported systems retain the previous switcher.

Install Leaf-0.1.0-alpha.23-x86_64.flatpak over alpha.22. Leaf is experimental and its development has used AI assistance.
