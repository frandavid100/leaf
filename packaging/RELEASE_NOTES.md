Leaf 0.1.0-alpha.22 includes the formatting, comments and Insert-menu fixes, plus the WordCraft printing integration from the previous source update.

The bundle includes WordCraft 0.14.0 and the existing ODT preservation safeguards.

- Font previews use the menu text size. The size field has an independent, compact width.
- Text and Paragraph use more compact layouts. Columns is available from the Paragraph toolbar, and Styles uses the WordCraft quick gallery where available.
- Write comments and threaded replies directly in the sidebar. Clicking a comment navigates to its anchor. Drafts retain the original selection.
- The document menu and the context menu share the Insert submenu.
- Printing uses the WordCraft 0.14 printer PDF API. Exported PDFs retain their links.
- Hidden Styles panels skip unnecessary updates. Keyboard, pointer and dialog code has been reorganized for easier review.

The dictionary installation link, column layout defects and additional break types remain under investigation. See docs/FORMAT_POPOVER_REVIEW.md.

Install Leaf-0.1.0-alpha.22-x86_64.flatpak over alpha.21. Leaf is experimental and its development has used AI assistance.
