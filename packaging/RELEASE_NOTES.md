Leaf 0.1.0-alpha.24 updates section properties, rulers and spell-checking dictionaries.

- Open Section Properties from Navigation, including for the first section. Page layout, columns, headers, footers and numbering apply to the selected section.
- Rulers show a translucent strip with a margin band and simpler centimetre marks, even when a page edge is scrolled out of view.
- Install supported Hunspell dictionaries from Text → Language by selecting the matching .aff and .dic files.

Install Leaf-0.1.0-alpha.24-x86_64.flatpak over alpha.23. Leaf is experimental and its development has used AI assistance.
