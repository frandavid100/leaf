## Leaf 0.1.0-alpha.44 — Native GNOME colors and a simpler frontend

- Color properties use GTK’s standard GNOME palette and custom-color editor again. Automatic text color, No Highlight, mixed selections, immediate edits and last-color actions retain their own meanings.
- Toolbar menus reuse their catalog and placement reads per group. Shared diagnostic scheduling reduces repeated frontend work while retaining the existing real-widget tests.
- An occasional Windows x86_64 installer and portable package are prepared separately from the same source, with the bundled GTK runtime and the final approved blue-quill icon.

WordCraft remains at 0.17.0. The remaining engine issues and incomplete List, Columns, Borders, Image and Table work from alpha.43 remain open. Store description and public screenshots (#185) stay paused.

Refactoring size and timing comparisons cover the measured Linux build and synthetic cases, not every document or Windows hardware. Windows packages are unsigned and still require real-user testing.

## Leaf 0.1.0-alpha.44 — Colores nativos de GNOME y una interfaz más sencilla de mantener

- Las propiedades de color vuelven a utilizar la paleta y el editor de colores personalizados estándar de GTK/GNOME. Se conservan Color automático, Sin resaltado, las selecciones mixtas, la aplicación inmediata y las acciones de último color.
- Los menús de herramientas reutilizan las consultas de catálogo y colocación por grupo. El registro compartido de diagnósticos reduce trabajo repetido sin retirar las pruebas gráficas existentes.
- Se preparan por separado un instalador y un paquete portable ocasionales para Windows x86_64, desde la misma fuente, con GTK incluido y el icono definitivo de la pluma azul.

WordCraft sigue en 0.17.0. Permanecen abiertos los problemas del motor y las partes pendientes de Listas, Columnas, Bordes, Imagen y Tabla de la alpha.43. La descripción y las capturas públicas (#185) continúan en pausa.

Las comparaciones de tamaño y tiempos corresponden a la compilación Linux y a casos sintéticos medidos; no representan todos los documentos ni equipos Windows. Los paquetes Windows no están firmados y necesitan pruebas de usuarios reales.
