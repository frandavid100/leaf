Leaf 0.1.0-alpha.7 adds English and Spanish throughout the native interface, help and accessible labels. The interface follows your system language; gettext catalogs are installed inside the Flatpak. Desktop/AppStream translations come from the same catalogs. Contributors can add languages through the documented PO workflow; Hosted Weblate activation still requires the owner’s account and service approval.

Document pages and thumbnails now follow GNOME’s light/dark appearance, using WordCraft’s existing screen-only color handling. Images retain their colors; saving, PDF export and printing retain document colors. The caret adapts for contrast. Live theme changes invalidate rendered pages without changing document content, selection or undo history.

Native and installed sandbox checks cover both languages and live dark/light changes, alongside existing editing, clipboard, lifetime and HiDPI regressions. Install Leaf-0.1.0-alpha.7-x86_64.flatpak over alpha.6. GNOME 49 runtime. No automatic update feed. Development and initial translations are AI-assisted; language review and real-document testing remain welcome. Existing accessibility and printing limitations remain documented.
