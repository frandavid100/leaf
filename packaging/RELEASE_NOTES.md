Leaf 0.1.0-alpha.9 adds Header, Footer and Page Number to the document menu’s Insert submenu. Headers and footers are edited directly on the page with the existing editing and formatting tools. Click existing header/footer text to edit it, or double-click an empty top/bottom margin to create one. Return to Document or Escape returns to the previous body selection.

Automatic PAGE and optional NUMPAGES fields can be inserted at the cursor or appended in a new header/footer paragraph. Existing content is retained; insertion is one undo step. Existing first/even/default variants use the story displayed by the selected page. Focused tests cover DOCX/ODT save/reopen, Unicode text, fields, history, later-page hit testing and empty-header cleanup. No new engine fork or dependency update.

English/Spanish, dark documents and the existing HiDPI/lifetime checks are retained. Install Leaf-0.1.0-alpha.9-x86_64.flatpak over alpha.8. GNOME 49 runtime; no automatic update feed. Weblate service activation is still pending. Existing compatibility, accessibility and printing limitations remain; this is an AI-assisted experimental editor. Test with copies of important documents.
