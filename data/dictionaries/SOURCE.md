# Spanish Hunspell dictionaries

Unmodified RLA-ES dictionaries from LibreOffice/dictionaries, commit 4f1df64b2e8e14751aa7c2205d170ca016071315, es/.
https://github.com/LibreOffice/dictionaries/tree/4f1df64b2e8e14751aa7c2205d170ca016071315/es

The original author/credit file and license are included. Leaf distributes these files under the offered GPL-3.0-or-later option; GPLv3.txt is included. No thesaurus or hyphenation data is copied. English proofing uses WordCraft’s existing built-in tools. Spanish varieties use the pinned engine’s documented dictionary fallbacks; selecting a language does not promise a dedicated regional dictionary.
