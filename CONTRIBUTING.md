# Contributing to the current Leaf editor

The current source and instructions are on **wordcraft-saving**. This default branch retains the earlier prototype as history.

- [Full contribution/build guide](https://github.com/frandavid100/leaf/blob/wordcraft-saving/CONTRIBUTING.md)
- [Architecture and feature-to-file map](https://github.com/frandavid100/leaf/blob/wordcraft-saving/docs/ARCHITECTURE.md)
- [Current status](https://github.com/frandavid100/leaf/blob/wordcraft-saving/PROJECT_STATUS.md) and [roadmap](https://github.com/frandavid100/leaf/blob/wordcraft-saving/ROADMAP.md)
- [Continuing guide](https://github.com/frandavid100/leaf/blob/wordcraft-saving/docs/CONTINUING.md)
- [Bug reports](https://github.com/frandavid100/leaf/issues/new/choose), English or Spanish welcome.

Target Leaf PRs at wordcraft-saving. Use public WordCraft APIs, preserve the pinned engine boundary and explicit ownership, and describe validation and AI assistance. Never attach confidential documents.
